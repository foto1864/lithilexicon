# Εισαγωγή φράσεων από συνομιλία

Πηγή: `chat.txt` (το αρχικό ιδιωτικό export διατηρείται, δεν ανεβαίνει στο Git ή στο hosting).
Το `chat.md` είναι δεύτερη μορφή του ίδιου export και δεν εισάγεται ξανά.

- 173 σημεία `#` σε γραμμές λημμάτων, εκ των οποίων ένα κενό.
- 172 καταχωρήσεις στο `entries.cleaned.json`, με τις αρχικές γραμμές για έλεγχο.
- 53 έχουν σημασία που δόθηκε με `=`. 119 έχουν κενή σημασία.
- Αφαιρούνται metadata, αναφορές σε συνομιλητές, emoji και επεξηγηματικά σχόλια από τους τίτλους.
- Δεν παράγονται σημασίες από παρενθέσεις ή σχόλια χωρίς `=`. Οι δοσμένες σημασίες δεν αποτελούν ανεξάρτητο λεξικογραφικό έλεγχο.
- Χωρίζονται τα πολλαπλά `#`. Παραλλαγές μέσα στο ίδιο `#` διατηρούνται μαζί.

Αναπαραγωγή και έλεγχος:

```sh
node scripts/clean-chats.cjs
node --test scripts/clean-chats.test.cjs
node scripts/import-chats.cjs
```

Το import χρησιμοποιεί τον υπάρχοντα λογαριασμό Firebase CLI και το project `lithilexicon`.
Με `--apply` γράφει ατομικά, κρατά ιδιωτικό `import-backup.json`, παραλείπει υπάρχουσες φράσεις και συμπληρώνει μόνο κενές σημασίες. Δεν αντικαθιστά υπάρχουσες σημασίες. Τα IDs είναι σταθερά και οι εγγραφές προστατεύονται με προϋποθέσεις ώστε να μην πατηθούν ταυτόχρονες αλλαγές.

Οι προτάσεις σημασίας αποθηκεύονται στη συλλογή `meaningSuggestions`. Διαχειριστής τις εγκρίνει από το dashboard, ενημερώνοντας την αρχική φράση χωρίς να δημιουργείται διπλότυπο.
